# Store URLs

- Support: `https://topchain.github.io/HouseFriends/`
- Privacy Policy: `https://topchain.github.io/HouseFriends/privacy.html`
- Terms: `https://topchain.github.io/HouseFriends/terms.html`
- Account deletion: `https://topchain.github.io/HouseFriends/delete-account.html`
- Fallback public support: `https://github.com/TopChain/HouseFriends/issues`

Enable GitHub Pages from the `main` branch `/docs` folder after the first push, then verify all three Pages URLs return HTTPS 200 responses before entering them in App Store Connect or Google Play Console.
